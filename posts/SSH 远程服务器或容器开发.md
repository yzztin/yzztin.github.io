# SSH 远程服务器或容器开发

## 1. 需求和原理
有时候，在本地电脑上可能无法做到运行一些需要服务器资源的项目，比如有些机器学习相关的项目需要较高的计算资源，只能在服务器上运行，而调试代码（进入 debug 断点、查看函数调用栈等）又几乎是必备的开发手段。这种情况下可以考虑远程调试开发代码：以本地 IDE 的形式，在**远程服务器**或**容器**中进行代码开发。

在本地 IDE 上做到：
1. 具备远程服务器的开发环境
2. 直接修改远程的代码
3. 无缝调试远程服务器上的代码

以 Python 项目开发为例，要想通过 IDE 调试代码，需要具备以下环境：
+ 项目运行的操作系统环境、必要的环境配置和工具（比如固件和驱动、环境变量的配置、编译工具等）
+ Python 解释器和项目依赖包（代码运行时）
+ 需要调试开发的项目代码，并且明确入口代码位置

因此，只要我们用的本地 IDE 具备上述环境，就可以实现调试开发项目代码，这完全可以通过 SSH、FTP 等协议实现。


## 2. 实现步骤
**以下的操作都以 VSCode 为例**

> 对于 JetBrains 类的 IDE（如 Pycharm）， 在查阅资料时，笔者发现其是支持远程开发和容器开发的，但尝试时却一直没有成功或体验较差，故此处仅作 VSCode 的示例
>

1. 点击上述图片中箭头执向的 IP 地址旁边的窗口图标，在新的窗口中打开服务器连接

3. 至此，我们已经在本地的 IDE 上可以自由地编辑远程服务器的代码，并且具备远程服务器的环境了，大概原理是：在远程服务器上装了一个 vscode，基于 SSH 协议让本机和远程服务器进行了资源通信。也就是说，我们只是在本地有了一个图形化的 IDE 界面去使用远程服务器的文件、环境等，因此，就需要再安装一些自己需要的开发插件来在 IDE 中开发调试代码（这些插件实质上是安装到了服务器上的）。



### 2.4 SSH 公私钥
可以发现，vscode 每次加载窗口、打开服务器文件等都会要求输入密码，有时候还会因为网络波动等问题重新连接要求输入密码，这很麻烦。

可以通过设置 SSH 密钥的方式，无感地做到远程服务器身份验证，即公私密钥验证的方式。简单来说，私钥文件只有你自己知道，公钥文件可以分化给任意的对象，只要两个密钥文件互相验证成功，就可以证明身份了。

**下面是基本步骤：**

1. 在本地生成公私密钥对，默认情况下会生成`~/.ssh/id_rsa`（私钥文件）和`~/.ssh/id_rsa.pub`（公钥文件），请注意，这会覆盖掉你原本的同名公私钥文件，你可以在生成密钥命令的提示中自行指定文件位置和名称

```bash
ssh-keygen -t rsa -b 2048
```


2. 为方便演示，我这边就指定一个非默认的密钥名称`id_rsa_60_245`，在`Enter passphrase`的提示中，可以直接回车不设置口令，当然你也可以设置一个密码口令来让你的密钥更加安全（如果设置了，那要记住这个口令，后续是需要的）
![](https://cdn.nlark.com/yuque/0/2025/png/45685561/1749175416238-1bd3a3bb-624e-4315-ac89-d1d0cc1dc72a.png)


3. 将本地的公钥文件的内容**追加**到远程服务器的`~/.ssh/authorized_keys`文件中，注意是追加，而不是覆盖，可能服务器的同一个用户有多个人使用，那肯定有不同的公私钥，在`~/.ssh/authorized_keys`文件中就可以配置多个公钥来让服务器去验证不同人的私钥


4. 权限设置，远程服务器的`~/.ssh`目录权限需为`700`，`authorized_keys`文件权限需为`600`


5. 在本地的 `~/.ssh/config` 文件配置服务器指定的私钥，还记得刚才 vscode 中配置服务器地址信息的文件名，添加指定密钥文件地址，修改为如下，这样，我们就成功匹配了本地的私钥和服务器的公钥，再不需要频繁的输入服务器用户密码了
![](https://cdn.nlark.com/yuque/0/2025/png/45685561/1749176485941-2c513632-c027-486f-b2a9-29e947d39e51.png)


### 2.5 远程容器开发
除了在远程服务器上开发，有时候，在远程服务器的 docker 容器上做开发也是常见的场景。

基于新版的 vscode `docker` 插件，这非常简单：（笔者落笔时间 2025.06.06）

1. 首先通过上述的方式在 vscode 中远程连接到服务器
2. 下载 vscode `docker` 插件
3. 在容器列表中选择你需要的容器，右键`附加 Visual Studio Code` 即可直接进入容器环境中（同理，这会在容器中下载 vscode 服务器）
![](https://cdn.nlark.com/yuque/0/2025/png/45685561/1749179334576-80d787c6-0f85-4947-86ac-a847d17ae6a4.png)

> 注：在较旧版本的 vscode `docker` 插件中，无此功能。彼时，我的基本思路是：在容器中安装 SSH，并暴露出一个额外的端口进行 SSH 通信（比如 2222 端口），在本机的 `~/.ssh/config` 中，连接服务器的端口改为容器的 SSH 暴露端口，这样当连接服务器时，就进入到了服务器的容器的环境中了。
>
